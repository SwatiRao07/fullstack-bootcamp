Design in Color

A deep dive into modern CSS color systems.

Drill 1 & 3: Interactive Components

Monochrome

Same hue, different lightness (30, 50, 70). Ideal for depth.

Complementary

Opposite hue (80°). Creates 180° contrast.

Triadic

Hue shifts of 120° and 240°. Balanced and colorful.

Drill 2: Visual Verification

Ensure code blocks and text remain readable in dark mode:

:root[data-theme="dark"] {
  --bg: oklch(18% 0.02 260);
  --text: oklch(95% 0.01 260);
}
